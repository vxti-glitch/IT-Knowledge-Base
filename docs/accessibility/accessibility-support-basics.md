## Summary

Support accessibility needs by asking what outcome the user wants, preserving their working configuration, and letting the user direct changes.

## Why support cares

Display, input, audio, speech, screen-reader, caption, and cognitive-access settings may be essential—not preferences to reset. A change that looks unusual to a technician may be the user’s primary way to work.

## Core concepts

- Ask how the user prefers to communicate and whether assistance is wanted.
- Describe each action before taking it and obtain consent.
- Record the working baseline before changing Narrator, Magnifier, contrast, text size, captions, voice access, keyboard/mouse, or app accessibility settings.
- Avoid taking control in ways that interfere with a screen reader or input device.
- Use Windows Accessibility settings and approved vendor documentation; involve an accessibility specialist for configured assistive technology.

## Examples and boundaries

If an application’s focus order prevents keyboard use, a local device reset is not an appropriate fix. If screen magnification appears after sign-in, ask before disabling it. Test updates in a safe context and confirm the user can complete the real task, not merely that a setting toggled.

## Related procedures

Use the audio/microphone, display/dock, safe remote-support, browser, and application troubleshooting guides while preserving accessibility configuration.
